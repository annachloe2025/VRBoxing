# 01_Docs

設計メモ・進捗日記・学習ノートを置くフォルダ。

## 推奨ファイル

- `step1_plan.md` - ステップ1の詳細計画
- `step2_plan.md` - ステップ2の詳細計画
- `dev_log.md` - 日々の開発ログ（詰まったところ、解決策）
- `design_notes.md` - ゲーム設計のメモ（キャラ設定、ルール）
- `learning_notes.md` - Unity / C# / VR 学習で覚えたこと
- `hit_physics.md` - パンチ判定・物理計算の設計メモ

## 書き方のコツ

- 日付を入れる（あとで見返すとき役立つ）
- 「詰まった → 解決策」をセットで書く（同じ罠にハマらない）
- 「なぜこの設計にしたか」を書く（3ヶ月後の自分は忘れている）
