# 素材全体ルール

`02_Assets_Source/` は**素材の元データ**を置く場所。Unity に取り込む前のオリジナルファイルをここに保管する。

## なぜ Unity プロジェクト外に置くのか

- Unity プロジェクトが壊れても元データが残る
- ライセンス情報やメモを素材と一緒に保管できる
- 複数のプロジェクトで使い回せる
- バックアップ対象が明確になる

## サブフォルダ

- **`Characters/`** — 3Dキャラモデル（.vrm, .fbx, .blend など）
- **`Animations/`** — モーション素材（Mixamo からダウンロードした FBX など）
- **`Audio/`** — BGM、効果音、ボイス（.wav, .mp3, .ogg）
- **`Textures/`** — テクスチャの元データ（.psd, .png の高解像度版）

## ライセンスメモは必須

!!! warning "これを怠ると将来泣く"

    素材ごとに `LICENSE.txt` や `SOURCE.md` を置くこと。**将来公開するときにどれが使えるか分からなくなる**。

書くべき項目：

- 入手元URL
- ライセンス種別（CC0 / 商用OK / 商用NG / 個人利用のみ など）
- クレジット表記が必要な場合の表記文
- ダウンロード日
