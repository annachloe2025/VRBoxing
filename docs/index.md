## 💡 このプロジェクトの目的

- **フィットネスとして続けられる** VR ボクシング体験を作る
- **女性キャラクターと対戦できる**（モチベーション維持の核心）
- Unity + VR 開発の学習も兼ねる
- 参考作品: [Thrill of the Fight](https://store.steampowered.com/app/651900/)（Ian Fitz 開発）

## 🎮 開発環境

| 項目 | 内容 |
|---|---|
| VRデバイス | Valve Index（Knuckles コントローラー） |
| エンジン | Unity 2022.3 LTS または Unity 6 LTS |
| VR SDK | OpenXR + XR Interaction Toolkit |
| 言語 | C# |

## 📁 プロジェクトのフォルダ構成

!!! info "リポジトリのフォルダ"

    **Git 管理（GitHub にアップ）:**

    - **`docs/`** — このドキュメントサイトの元ファイル（MD）

    **ローカル限定（Git 管理外）:**

    - **`unity/`** — Unity プロジェクト本体
    - **`blender/`** — キャラ素材・Blender 作業ファイル
    - **`refs/`** — 参考資料・PDF・スクショなど

    重いバイナリは GitHub に上げず、各自のローカルで管理する方針（2026-04-26〜）。

## 🛠 更新のしかた

MD ファイルを書き足す／編集したら、プロジェクトフォルダの **`update.bat`** をダブルクリック。それだけで：

1. コミット
2. GitHub に push
3. このサイトを再ビルド＆デプロイ

まで全部自動です。
