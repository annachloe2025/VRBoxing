# ビルド

ビルド成果物（`.exe` など）は **`unity/Builds/`** に置く（Unity の標準的な置き場）。

## 推奨フォルダ命名

```
unity/Builds/
├── 2026-04-30_v0.1_first_punch/     ← 日付_バージョン_ひとこと
├── 2026-05-15_v0.2_ai_idle/
└── ...
```

- 日付を先頭にすると時系列で並ぶ
- バージョン番号 + 内容のメモを入れておくと、「この時点ではどこまで動いた」が分かる

## ビルドのコツ

!!! tip "区切りで必ずビルド"

    - 区切りのいいタイミングで必ずビルドする（ステップ完了時など）
    - ビルドしてみると Editor では気づかない問題が見つかることがある
    - 友達に見せたくなったとき、すぐ渡せる
    - **0.1 単位でもバージョンを刻む**（消さずに残す）

## 注意

- ビルドデータは大きい（数百MB〜数GB）
- `unity/` フォルダ全体が `.gitignore` 対象なので **GitHub には自動的に上がらない**
- 共有したいビルドは `refs/` 経由かクラウド（Google Drive / OneDrive 等）に置く
