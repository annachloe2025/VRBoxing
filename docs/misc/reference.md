# 参考資料

`05_Reference/` に参考資料を置く場所。自分のメモとは分ける。

## 置くもの

- **Thrill of the Fight の分析メモ**
    - プレイして気づいた挙動
    - スクリーンショット／録画からの観察
- **参考動画のURL一覧**
- **技術記事・チュートリアルのPDF保存**
- **他のVRボクシングゲームの比較メモ**
- **参考画像**（キャラデザイン、ジムの雰囲気、UI）

## サブフォルダ例

```
Reference/
├── ThrillOfTheFight/
│   ├── observation_notes.md
│   └── screenshots/
├── Tutorials/
│   ├── unity_xr_setup.pdf
│   └── links.md
└── Inspiration/
    ├── character_design/
    └── gym_atmosphere/
```

## なぜ分けるか

自分が書いたメモ（`docs/`）と、他人の作ったもの（`05_Reference/`）を混ぜると、**「これ自分の考えだっけ？どこかで読んだやつだっけ？」**が分からなくなる。

最初から分けておくと、ブログや動画にまとめるときに引用元が明確になる。
